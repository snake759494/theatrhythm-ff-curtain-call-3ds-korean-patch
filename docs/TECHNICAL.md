# 기술 설명

## 파일 구조

- ROM은 CCI(.3ds) 안의 CXI 하나에 게임 데이터가 모두 들어 있습니다. 3dstool로 exefs·romfs를 풀고, 바뀐 romfs로 다시 묶습니다. 실행 파일(exefs)은 고치지 않았습니다.
- 문장은 `message/*_jp.mdt`(메시지 표)와 `text/*.tdt`(화면별 문자열)에 UTF-16으로 들어 있습니다(`fmt.py`). 줄 안의 `\x02` 계열 색·강조 제어 코드는 원문 그대로 두고, `tdt`는 `\n` 줄바꿈을 지원합니다.
- `table/*.csv`는 UTF-16 쉼표 구분 표입니다. 이름 열만 바꾸고, 한국어 안의 쉼표는 공백으로 바꿉니다.

## 아카이브와 레이아웃

- 화면 자원은 LZ11로 압축한 darc(`*.arc.lz`)입니다(`arc.py`). 안에 레이아웃(`bclyt`), 그림(`bclim`), 글꼴(`bcfnt`)이 있습니다.
- `clyt.py`는 `bclyt`의 txt1 패널 문구를 대조표로 바꾸고, 그 패널이 쓰는 글꼴 이름을 돌려줍니다. 원문이 저장소에 없는 레이아웃 문구는 원문 SHA-1을 열쇠로 찾습니다.

## 글꼴

- 아카이브마다 들어 있는 `bcfnt`를 풀어(`bcfnt.py`), 그 아카이브의 문장과 레이아웃 문구에 쓰인 한글만 추가합니다. 원본 일본어 글리프의 굵기·높이·외곽선을 재서(`style.py`) 비슷한 모양으로 그립니다.
- 게임은 각 글리프 칸의 맨 왼쪽 열을 그리지 않습니다. 이 열에 잉크가 닿는 글리프는 1픽셀 오른쪽으로 옮기고 왼쪽 여백을 1 줄여 화면 위치를 유지합니다(`pad_col0`). 이 처리가 없으면 「어」처럼 왼쪽이 넓은 글자의 앞이 잘립니다.
- 본체 공용 글꼴을 쓰는 화면을 위해 `font/cbf_std_replace.bcfnt`를 새로 만듭니다.

## 그림 글자

- `bclim`은 ETC1·ETC1A4·RGB8 등 형식을 읽고 같은 형식으로 다시 씁니다(`bclim.py`, `etc1.py`).
- `imgpatch.py`·`textimg.py`는 원본 글자 영역을 지우고 같은 자리에 한글을 그립니다. 높이가 아주 작은 글자는 갈무리로 그립니다.
- 타이틀 로고는 본체·흰 실루엣·별도 문구 띠 세 장 모두에서 일본어 문구 자리만 「시어트리듬 파이널 판타지 커튼콜」로 바꿨습니다.
- 어빌리티·아이템·소환수 이름판은 `plate.py`가 표의 한국어 이름으로 다시 그립니다.

## 컬렉카 뒷면

- `common/image/card/ura_NNN.bclim.lz`(366×512, RGB8)에서 이름 줄과 설명문 줄을 색·에지로 찾아 지우고(인페인팅), 나눔스퀘어네오로 다시 씁니다(`ura.py`). 설명문은 원래 줄 간격과 폭에 맞춰 줄을 나누고 글자 크기를 고릅니다.
- 컬렉션 화면은 별도의 축소 그림 `card_thumbnail/colleca_back_NNN.bclim.lz`(160×224, ETC1A4)를 씁니다. 한글 뒷면을 축소하고 원본의 둥근 모서리 알파를 그대로 씁니다.

## 검증

- Azahar를 백그라운드로 띄워 창 메시지로 버튼·터치를 넣고, 스크립팅 RPC(`save_screenshot`)로 화면을 저장해 확인했습니다.
- 진행이 필요한 화면은 확인용으로만 LayeredFS 모드(노트를 줄인 악보, 몬스터 HP 1 등)를 얹어 열었습니다. 배포 ROM에는 이런 변경이 없습니다.
